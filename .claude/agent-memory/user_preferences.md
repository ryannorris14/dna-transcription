name: User Preferences
description: Ryan's feedback preferences and design sensibilities for this educational bio project
type: user
---

- Wants animations to be the star — 3D helix and pipeline cascade should feel alive, not static
- Prefers the info panel to be secondary to the visual/3D content (smaller side panel, bigger helix)
- Likes "cursed" creature aesthetics to engage kids (wonky eyes, weird shapes)
- Wants processes shown through time, not instant (staged reveals, cascade animations)
- Values keeping old creature visible for comparison during edits
- Wants biological accuracy as a priority (pair-by-pair helicase, polymerase on template strand, correct strand separation)
- Appreciates smooth transitions between states
- Thinks about student experience on small laptops — layout must work without scrolling for key info
- Audience: middle school students on personal laptops
- Deploys to Vercel from GitHub
